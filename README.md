# Adaptive-Multi-Map-Lokalisierung

The project proceeds in several consecutive phases. First, during the requirements analysis and research phase, the current state of the art is thoroughly examined, relevant technologies are identified, and the specific challenges of transitioning between indoor and outdoor operation are assessed. This is followed by the conceptual phase, in which theoretical models and designs for adaptive sensor fusion and the integration of multiple maps are developed. Building on this, the next phase involves implementing the system and testing it in the form of a prototype—both in real and simulated scenarios. Finally, an evaluation is conducted, during which the test results are systematically analyzed and potential areas for optimization are identified. This structured approach forms the foundation for the development of an innovative localization system that enables forward-looking applications in areas such as logistics, urban mobility, and agriculture.
